# Tab Constellation Privacy Policy

Last updated: February 25, 2026

Tab Constellation is a Chrome extension that automatically groups your browser tabs by domain to keep your tab strip organized. This policy explains what data the extension accesses and how that data is used.

## Data the extension can access

Tab Constellation uses the following Chrome extension permissions:

- `tabs` and `tabGroups`: to read the URLs and properties of your open tabs and to create, update, and remove tab groups.
- `host_permissions: "<all_urls>"`: to inspect the URL of any tab so it can be grouped by domain.

This access is used **solely** to determine which tabs belong together in a group within your own browser.

## What data is collected

Tab Constellation:

- **Does not** collect, log, or persist any browsing history outside of your local browser memory.
- **Does not** send any data to external servers or third parties.
- **Does not** use analytics, advertising SDKs, or tracking pixels.
- **Does not** create user accounts or handle any authentication data.

All processing happens locally in your browser’s memory and is limited to what is required to group your tabs by domain.

## Data sharing

Because the extension does not transmit or store your data outside of your browser, there is no data shared with the developer or with third parties.

## Data retention

The extension does not retain data beyond what Chrome itself keeps in memory for normal tab operations. Tab information is only used transiently to decide how to group tabs in the current window.

## Remote code

Tab Constellation does not load or execute remote code. All extension logic is packaged with the extension and reviewed as part of the Chrome Web Store submission.

## Changes to this policy

If this privacy policy changes in a way that affects how your data is handled, the policy will be updated and a new version will be published in the extension’s source repository and, where applicable, on the Chrome Web Store listing.

## Contact

If you have questions about this privacy policy or how Tab Constellation handles data, please open an issue on the project repository.
